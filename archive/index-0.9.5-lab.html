Vision · trait-evolution-sim

An agent evolution lab: spatial agents in a 2D world. Watch what helps them last — then, over phases, what helps them thrive.

What this is
Project id trait-evolution-sim — a single-file, observable simulation. Two modes: World (live canvas) and Lab (headless multi-setup batches). Same engine, same knobs.
Where we are · Survive
Phase 0 · Survive (path on the world frame). Core loop: get hungrier, find food, starve or persist. Seek vs Random, difficulty presets, special agent, run-log export, and Lab Monte Carlo are in. We are near Differ in the roadmap sense — not in Phase 1 yet.
Where we’re going
Differ — traits; agents become heterogeneous by design.
Evolve — generations, inheritance, mutation; tune who thrives across runs.
Economy — trade, storage, production, labor… a micro-economy on the same substrate.
The dream: use this desk to develop strong survival (and later economic) setups by tuning — multi-run Lab experiments today; generation-level selection in Evolve later. Playbook recipes and graphs are still later Phase 0 polish.
How to use today
World — feel one run; Special… for a probe agent; Run logs… for single-run JSON.
Lab — compare 1–5 crowd setups over many seeds; Export / Copy last batch. No special in Lab.
Help covers knobs and how to read Lab metrics. Path on the canvas shows Survive → Differ → Evolve → Economy.

Help · how the lab works

Agents get hungrier over time. Hunger past 100 → death. They pick up ground food and can self-eat carried food when hungry enough. Tune the world (left rail), optionally one Special agent, then use Run logs… to export evidence. Long product arc: Vision….

Header & run control
Pause / Resume — Stops or starts the sim clock (ticks).
Reset — Ends the current run (records it), respawns agents + food, starts a new run number.
Speed 1×–10× — How many sim steps per animation frame. Higher = faster die-off and less smooth motion.
Special… · Help · Vision… — Popups for overrides, this guide, and the Survive→Economy roadmap.
Movement policy
Seek — Home toward nearest food inside sense radius. Hunger scales how hard they commit (see seek strength). Residual wander remains so paths aren’t perfect lasers.
Random — Pure wander (no food targeting). Baseline for “no sense.” Same hunger/food world should usually kill Random faster than Seek.
Classic A/B: Balanced + Seek vs same + Random. Or world Random + Special Seek (amber still forages).
Movement knobs (world · left rail)
Sense radius — Max distance to “see” food for seeking. Outside range → no seek target (wander only until food enters range). Default 180; special can go to 400.
Seek strength — Seek mode only. Scales how much hunger becomes steering pull (blend). 0 ≈ almost no seek; 2 = hungry agents commit hard even at moderate hunger.
Seek accel — How hard velocity is shoved toward the food target each tick. Higher = snappier turns / faster close-in. Often more decisive than sense alone in a crowded Seek world.
Wander amp — Size of the random kick each tick. Higher = more exploration and noise; can help leave empty patches or hurt by missing pellets.
Max speed — Speed cap. Higher = can cross the map faster (and overshoot more).
Inspector seek blend = “how hard is this agent seeking right now?” (from hunger × seek strength). Distance-to-food shows if they currently have a target in range.
Environment
Initial agents — Count at next Reset (not mid-run).
Hunger rate — Hunger gain per tick. Higher = harsher.
Food spawn interval — Ticks between food drops. Higher = rarer food = harder. (Interval is in sim ticks, not wall-clock seconds.)
Difficulty presets
Lenient — Soft hunger/spawn/eat pack. Demos and “does Seek look right?”
Balanced — Default lab pressure.
Punishing — Stress test; remnants only with good forage + luck.
Presets set hunger, food spawn, and Advanced eat knobs. They do not set Seek/Random or sense/seek/wander/maxSpeed. Dragging a preset-linked slider → custom.
Advanced… (eating / metabolism)
Ground eat relief — Hunger removed when eating ground pellets (main rescue).
Self-consume threshold — Hunger level before they nibble carried food.
Self-consume amount — Carried food used per nibble tick.
Self-consume relief — Hunger removed per nibble.
Ground food = emergency meal. Carried food = backup once already quite hungry.
Special agent
One amber agent. Each knob can custom or match world (policy, sense, seek strength/accel, wander, max speed, hunger, eat). Match all → world clears customs.
Pin ≠ special — Pin only selects who you chart. Special selects who uses different rules. Focus/pin and Reroll body live in Special…
In an all-Seek world, a “slightly better” special often still dies ~40s — advantage is relative. In a Random world, Seek special is usually obvious.
Live metrics (left dock)
Alive / Deaths — Living count · starvation deaths this run.
Food — Pellets on the map (not inventories).
Avg hunger — Mean hunger of living agents.
Min / Max food — Min/max carried food among living (not hunger).
Avg food / agent — Mean inventory. High avg food late often means a fat remnant (or one loaded special).
Canvas · select · pin
Click an agent: id, hunger, carried food, effective policy, seek blend, distance to food. Pin to trends keeps their series on the right after you click away.
Phase path on the world frame is Survive → Differ → Evolve → Economy (roadmap chrome, not sim state).
Trends (right)
Population, map food, and average hunger over the current run. Optional pinned-agent hunger/food if you pin someone.
History strip & Run logs…
Strip = last 3 finished runs. Run logs… = full table (click a row for knobs + special), Export/Copy last & all as pretty JSON for analysis (e.g. paste to Grok).
Pre preset · Pol seek/random · N initial agents · Dur / Long run length & longest life · Dead / Fin deaths & final pop · Hung / Food run averages · End extinction vs reset · Sp special custom override count.
JSON envelope: { version, exportedAt, runs: [...] } with world knobs + special block (including lifeSec even if the special died).
Export after a ladder of special overrides (sense → strength → accel → wander) is a great way to see which knobs actually buy a seat in the remnant.
What “seconds” mean
History Dur / Long / lifeSec use sim time: ticks ÷ 60 (not wall-clock). At 10× speed, wall time is much shorter than Dur.
