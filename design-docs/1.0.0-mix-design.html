5. Proposed design

Hunt decode (Track B)

Piecewise linear. Most remnant drama in 0–0.5. Do not call applySeekMaster.

tMeaningsighthungerPullseekPush
0hunt OFF4000.05
0.5today’s control1801.00.35
1full lock2801.750.60
function decodeHunt(t) { t = clamp(t, 0, 1); if (t <= 0.5) { const u = t / 0.5; return { sight: lerp(40,180,u), hungerPull: lerp(0,1,u), seekPush: lerp(0.05,0.35,u) }; } const u = (t - 0.5) / 0.5; return { sight: lerp(180,280,u), hungerPull: lerp(1,1.75,u), seekPush: lerp(0.35,0.60,u) }; }

Extend p(): Special first, then agent.traits[key] != null, then globalParam. PR 2 must write hungerRate, efficiency, maxSpeed, sight, hungerPull, seekPush into traits{} (plus hunt for inspector). Mute Parameters rows Mix owns.

World rail (thin)

Keep: Island L/B/P (food only), Parameters… (no Policy), Mix…, KPIs, inspector. Remove rail: Policy, Seek/Agent masters. Hide Policy in World Parameters. Do not merge this strip to live without PR 2.

Canvas layering (exact)

  • Fill = group #38bdf8 / #c4b5fd / #4ade80 / #fb923c, radius 3+sqrt(food)*0.5.
  • Starve stroke if hunger>75: #fb7185, width 2, radius size+1.5. Do not replace fill with pink.
  • Bag pip if food>6: #22d3ee r=1.2 (not old cyan — collides with group green).
  • Special ring outermost if ever on: #fbbf24 width 2, size+3.5, amber shadow. v1: Special off.

Fair-eat

First-in-array pellet win systematically favors earlier groups. PR 2: random winner among in-range agents using the run RNG. Shuffle at spawn is not enough (filter/eat re-orders). Uniform Lab remnants do not measure this bias.

Model

Palette: #38bdf8 · #c4b5fd · #4ade80 · #fb923c. v1 groups are point masses. Mix sliders use band min/max. Import: warn outside band, reject outside engine. Defaults below are provisional (uniform Lab), not a locked scientific band.

N vs island (one rule)

L/B/P stay enabled and change food spawn only. They never mutate pendingMix group counts (no silent rescale, no match-N toast). Mix owns N. If Mix N ≠ that preset’s table N (L35 / B60 / P80), show a custom N chip; last weather button may stay highlighted. Parameters N slider enabled only for 1-group mixes.

JSON: version === 1 (number only). Optional name. 1-group import: one card, Add on, Remove off. cloneMix normalizes into Object.create(null).
