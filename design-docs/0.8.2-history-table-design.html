0.8.2 History · Table D+

Chosen direction: table with more metric columns, session summary = best run only (top-right). Left inspector dock stays (confirmed good).

design lock-in
Locked decisions
  • History = table (D+) — not cards, not dual best callouts.
  • No Session Overview box — no “Runs / Ext / Best” dump.
  • Best once — top-right of history panel only (duration + run # + preset).
  • No status / endedBy column — extinction is implied when End === 0 (shown in red).
  • End = 0 → red number (alive survivors stay default/neutral).
  • Preset — plain short text, color only (no badge/chip background). lenient green · balanced blue · punishing red · custom yellow.
  • Columns — # · Pre · Dur · End · Hung · Food.
  • Pin-by-ID lives in left inspector dock (already good).
  • Live metrics — rename Avg H → Hunger (avg).
