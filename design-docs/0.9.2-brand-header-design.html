4. Recommendation

Header brand (next)

Prefer N1: mono trait-evolution-sim · Agent evolution lab · quiet version.
Optional N2 if “Project name” label is required. Optional Vision… next to Help.

Phase path (live direction)

P3 on canvas-module top chrome (connected to world, not in agent field).
No “You are here” / no lab text on the path — only dots + Survive…Economy.

Combo for 0.9.3-vision: N1 header + Vision modal + P3 path on canvas module. Long arc prose lives in Vision, not under the title.
Don’t: make Differ/Evolve/Economy look clickable-unlocked if content isn’t there — use future styling + optional tooltip “coming later.”
