Structural rules

RegionContentSizing
Header Title, phase label, version badge, speed 1×/2×/5×/10×, Pause, Reset Full width, fixed height, no wrap if possible
Left column Controls (sliders, presets, Advanced collapse) + compact live metrics ~200–240px fixed; independent scroll if needed
Center Canvas + floating inspector (bottom-right of canvas) flex: 1; column stretches to bottom of viewport shell; canvas fills center cell

No bottom trends dock. Unlike early Layout B, charts live only in the right column. Canvas reaches the bottom of the app shell.

Viewport shell

/* App fills useful viewport under page chrome */ .app-shell { height: calc(100vh - <page-padding>); /* ~ calc(100vh - 2–3rem) if full-bleed body */ min-height: 520px; display: flex; flex-direction: column; gap: 0.5rem; } .app-body { flex: 1; min-height: 0; display: grid; grid-template-columns: 220px minmax(0, 1fr) 300px; gap: 0.5rem; }

Canvas sizing policy

  • Center column is fluid; canvas element should fill the center cell (CSS width/height 100% of the cell).
  • Keep internal simulation coordinates consistent: either (a) resize canvas buffer to client size on load/resize, or (b) keep logical 800×600 and letterbox scale with CSS. Prefer (a) if agents already use canvas.width/height.
  • On resize: update canvas buffer, keep agents in bounds (clamp or leave wrap logic as-is).

Pin / trends / history behavior

StateTrends panelHistory panel
Default (no pin) Main 3 charts only (Population, Total Food, Avg Hunger). Compact height (~40px charts). Panel max ~48% of right column. Gets remaining space. Floor: min-height: max(200px, 42%) of right column.
Pinned Show pinned block (Hunger + Food carried) under main charts. Charts slightly taller (~52px) for pinned only. Panel max ~55%; overflow-y: auto so content scrolls inside trends. Does not collapse. Keeps the same floor. May shrink only within flex remaining space above the floor.
Unpin / Remove Hide pinned block; main charts stay compact. Reclaims any freed flex space.
Do not increase the height of the three main run charts when pinning. That was the squeeze bug in the F mock — only the pinned agent charts may grow slightly, and trends must scroll rather than steal history’s floor.
#right-trends { flex: 0 1 auto; max-height: 48%; overflow: auto; } #right-trends.pinned { max-height: 55%; } #right-history { flex: 1 1 auto; min-height: max(200px, 42%); overflow: auto; display: flex; flex-direction: column; }
