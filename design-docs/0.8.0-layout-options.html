A — Lab Bench

recommended default

Everything useful visible; tabs retired on desktop. Canvas + always-on right rail (controls + metrics + history), trends full-width under the sim for real chart room.

Pros
  • Natural watch + tweak loop
  • Charts get horizontal space
  • Balanced density without feeling sparse
Cons
  • Right rail can get long (scroll)
  • History competes with controls for height
Best if…

You want a “lab bench” default for Phase 0→1 and still care about watching the canvas first.

Mix-friendly

Steal B’s KPI strip; steal D’s larger trends pane height.

B — Command Center

ops room

Live KPIs always on top, history as a session log on the right, trends docked full-width at the bottom. Strong “mission control” feel while tuning.

Pros
  • Metrics never hidden
  • History always scannable
  • Bottom trends scale well
Cons
  • Canvas is smaller vertically
  • More chrome; can feel busy
Best if…

You run many short experiments and live numbers + log matter as much as the dots.

Mix-friendly

Top KPI strip pairs well with A or E. Bottom trends dock pairs with C.

C — Observatory

canvas-first

Watch first. Big canvas, metrics as HUD chips, controls in a collapsible drawer, trends + history in a bottom sheet. Tabs reserved for compact/focus later.

Pros
  • Best for demos & “feel” of agents
  • Clean cinematic stage
  • Natural home for future trails / paths
Cons
  • Analysis secondary (sheet height limited)
  • More interaction to reach history/trends
Best if…

0.9.0 forage paths and agent stories matter more than constant chart watching.

Mix-friendly

HUD chips can sit on A/B canvas. Drawer controls work with any layout.

D — Quad Analysis

equal citizenship

True 2×2: canvas · trends · controls+metrics · history. Analysis is not a sidebar afterthought — ideal for parameter science and future greed high/low comparisons.

Pros
  • Best multi-signal visibility
  • Room for Phase 1 distribution charts
  • Strong “lab notebook” metaphor
Cons
  • Canvas loses primacy
  • Can feel like a spreadsheet, not a world
Best if…

You’re optimizing runs and comparing outcomes more than staring at individual dots.

Mix-friendly

Take the wide trends pane only; keep A’s canvas scale.

E — Stacked Rail

lowest risk

Closest to today’s chrome: canvas left, one taller/wider right rail, no tabs — Controls → Metrics → Trends → History stacked with section scroll. Widen past max-w-5xl.

Pros
  • Smallest code/mental jump
  • Kills the main pain (hidden tabs)
  • Easy to implement first
Cons
  • Trends stay narrow
  • Long scroll on the rail
  • Less “redesign,” more cleanup
Best if…

You want 0.8.0 shipped fast, then iterate layout again after 0.9.0 forage.

Mix-friendly

Good stepping stone toward A (peel trends under canvas next).
