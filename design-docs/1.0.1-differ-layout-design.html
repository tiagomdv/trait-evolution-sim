1. Names

Desk was our shorthand for “the panel where you set the experiment.” Mix was the spawn recipe (who is in the crowd). Both read like kitchen jargon, not the phase.

In the UI, sayNotWhy
Differ… (button + modal title) Mix…, Mix desk, Crowd desk Same word as the phase. You open it to make agents differ.
Groups / Roster (tabs in that modal) Mix modes, cards vs individuals One crowd of types, or a list of bodies.
Apply on Reset (footer hint) Commit pending mix Matches the Reset button they already know.
Parameters… — Weather + leftover sliders. Unchanged name.

Older files still say “mix” in code sketches. Layout + this PR copy use Differ….

3. Left column — this PR

Top to bottom. Tight. One primary action.

  1. Differ… — full-width, strongest button. Subline = applied crowd (“2 groups · 60 agents” or “Roster · 60”). If the modal was edited but Reset not pressed, subline reads pending — Reset to apply.
  2. Parameters… — secondary. Food spawn lives here. N slider hidden or read-only (N comes from Differ…).
  3. One line of weather: N 60 · food 8.
  4. Live: Alive + Deaths (keep today’s tiles if cheaper). Optional one row of alive per group color — only if it stays a small strip, not a second dashboard.
  5. Inspector: click on canvas. Show name/id, group color, hunger, bag, four traits. No Pin button in the new layout (can leave the old Pin in the DOM unused, or hide it). Search jumps to an agent; it does not pin charts.
Bag-food KPI tiles and Pin-to-trends can remain in the file this PR if ripping them out is extra work. Prefer hide over a big metrics redesign.

4. Differ… modal — chrome

Same modal shell as Parameters / Lab: overlay, panel, close. Wider than Parameters (room for a list + an editor).

  • Title: Differ
  • Tabs: Groups | Roster
  • Left: the list (group cards or roster table)
  • Right: editor for the current selection (the four traits + name + color)
  • Footer: Import · Export · Close. Hint: Applies on Reset. No live “apply now.”

Default open tab: Groups. Switching Groups → Roster expands cards into rows. Roster → Groups asks before folding look-alikes.
