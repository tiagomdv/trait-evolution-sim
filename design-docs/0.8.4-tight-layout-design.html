0.8.4 Tight layout

Design only. Goals: 260 / fluid / 260 (or similar), column hide toggles inside columns, no canvas padding, charts full column width.

preview before implement
Problems with 0.8.3 attempt
  • Header toggles + big fr-grid + stretch canvas felt like too much chrome.
  • Charts stayed ~240px wide while the column was wider.
  • History flex was fine; hide UX was in the wrong place.
Locked directions (this design)
  • Grid: 260px · 1fr · 260px — both sides tight and equal; canvas takes the middle. (Optional alt: right 280 if table feels tight.)
  • Hide toggles: live on the column (top of left / right panel), not in the global header.
  • When hidden: a slim edge tab on the canvas side re-opens that column.
  • Canvas host: padding: 0 — sim flush to the panel border (no empty frame).
  • Charts: width 100% of right column (already fixed in live; keep in this design).
  • History: still flex-fills leftover right height (from 0.8.2–0.8.3).
