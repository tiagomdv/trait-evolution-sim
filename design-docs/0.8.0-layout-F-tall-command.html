Layout F — spec notes (for final 0.8.0 design)

Structure
  • Header row: title, phase, version badge, speed 1×/2×/5×/10×, Pause, Reset
  • 3 columns fill remaining viewport height (no bottom band)
  • Left (~200–240px): Controls + optional compact metrics
  • Center (flex): Canvas grows to full column height (aspect or letterbox TBD)
  • Right (~280–320px): Trends on top, History below — both live in one column stack
Pin expand behavior
  • Default: main 3 trend charts compact; history gets most of the right column
  • Pinned: show Hunger + Food charts in trends; trends max ~55% and scrolls; main run charts stay compact
  • History floor: min ~42% / 200px so pin never crushes the session log
  • Unpin / Remove: hide pinned block; trends shrink to content
  • No bottom graph dock (unlike original B)
Pros
  • Max canvas presence
  • B-style ops header you liked
  • Analysis stays on the side, not under the world
  • Pin gets room without leaving the column
Tradeoffs
  • Trend charts are narrower than a full-width bottom dock
  • Need good min-heights so pin doesn’t crush history to zero
  • Canvas aspect ratio on ultrawide needs a rule (contain vs stretch)
Open choices
  • Metrics: left column vs thin header KPI strip
  • Canvas: fixed 800×600 centered vs fluid fill
  • Column widths: fixed px vs % with minmax
