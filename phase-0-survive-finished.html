Vision · trait-evolution-sim

An agent evolution lab: spatial agents in a 2D world. Watch what helps them last — then, over phases, what helps them thrive.

What this is
Project id trait-evolution-sim — a single-file, observable simulation. Two modes: World (live canvas) and Lab (headless multi-setup batches). Same engine, same knobs.

Help · how the lab works

Agents get hungrier over time. Hunger past 100 → death. A catch puts 1 food in the bag (no instant hunger drop). They eat from the bag when hunger crosses Eat threshold. World = canvas. Lab = headless batches. Arc: Vision….

World | Lab
World — Live canvas, left rails, trends, history, Special… Pause/Reset/Speed apply here. Enter Lab pauses World.
Lab — No canvas. Compare 1–5 crowd setups over many seeded headless runs. Special is World-only (would muddy batch stats).
Default Lab experiment: three setups, all Random — Lenient / Balanced / Punishing island packs (Food spawn + Initial agents).
Lab desk
Parameters… — Per-setup Environment / Seek / Agent (same names as World), including Seek master and Agent master (same paths as World). Batch tab: runs per setup, stop prefer, max duration. N is per setup.
Stop prefer · All dead — End early on extinction; max duration locked to 600 sim-s safety so soft worlds cannot hang forever.
Stop prefer · Max time — Cut each trial at the duration slider (default ~90s; editable 15–600). Best for ranking remnant size on short clocks.
Start batch / Cancel — Sequential headless trials with progress. Cancel keeps partial results. Last batch only (no history).
Export batch / Copy all — Pretty JSON { version, mode: "lab", experiment, runs, aggregates } for analysis (e.g. paste to Grok).
How to read Lab metrics — Prefer avg alive / dead under a fixed short Max-time (e.g. 75–90s) for difficulty ladders. Long All-dead runs can leave 1–2 “tycoon” survivors with huge avgFood; mean duration can look “mid” while alive stays ~0 when many seeds wipe early and a few ride the wall. Random is harsher than Seek on the same island. Use Lab to sweep Seek / Agent masters.
Header & run control (World)
Pause / Resume — Stops or starts the sim clock (ticks). Disabled look while in Lab.
Reset — Ends the current run (records it), respawns agents + food, starts a new run number.
Speed 1×–10× — How many sim steps per animation frame. Higher = faster die-off and less smooth motion.
Special… · Help · Vision… — Popups for overrides, this guide, and the Survive→Economy roadmap.
Policy
Seek — Aim at nearest food inside Sight. Hunger pull scales how hard they commit. Drift remains so paths aren’t lasers.
Random — No food targeting. Drift only. Same island should usually kill Random faster than Seek.
Classic A/B: same island, Seek vs Random. Or island Random + Special Seek.
Parameters… · Environment (island)
Initial agents — Count at next Reset.
Food spawn — Ticks between drops. Higher = scarcer.
Island presets Lenient / Balanced / Punishing set only those two. Not Policy, Seek, or Agent.
Parameters… · Seek
Seek master — On the left rail (and in Parameters). Path: more Sight / Hunger pull / Seek push, less Drift. Mid ≈ default. Child slider → custom.
Sight — How far they notice food (Seek only).
Hunger pull — How hard hunger aims them at food.
Seek push — Acceleration toward the target.
Drift — Random kick each tick (both policies).
Parameters… · Agent
Agent master — On the left rail (and in Parameters). Easy → hard body. Child slider → custom.
Max speed — Hard cap after acceleration.
Hunger rate — Hunger gained each tick (energy use).
Gluttony — Food taken from the bag per nibble (meal size).
Efficiency — Hunger dropped per 1 food eaten. Hunger −= Gluttony × Efficiency.
Eat threshold — Hunger before they nibble the bag. Not hoarding.
Catch banks 1 food and deletes the pellet. No ground-fill hunger drop. Pellets are fixed size.
Special agent
One amber agent. Override Policy, Seek, or Agent. Seek / Agent masters write the whole shelf as customs (same paths as World). Island stays shared. Match all → world clears customs.
Pin ≠ special — Pin charts someone. Special changes their rules.
In a Random world, a Seek special is usually obvious. In all-Seek, a small edge often still dies.
Live metrics (left dock)
Alive / Deaths — Living count · starvation deaths this run.
Food — Pellets on the map (not inventories).
Avg hunger — Mean hunger of living agents.
Min / Max food — Min/max carried food among living (not hunger).
Avg food / agent — Mean inventory. High avg food late often means a fat remnant (or one loaded special).
Canvas · select · pin
Click an agent: id, hunger, carried food, effective policy, seek blend, distance to food. Pin to trends keeps their series on the right after you click away.

History strip & Run logs…
Strip = last 3 finished runs. Run logs… = full table (click a row for knobs + special), Export/Copy last & all as pretty JSON for analysis (e.g. paste to Grok).
Pre preset · Pol seek/random · N agents · Dur / Long run length & longest life · Dead / Fin deaths & final pop · Hung / Food run averages · End extinction vs reset · Sp special custom override count.
JSON envelope: { version, exportedAt, runs: [...] } with world knobs + special block (including lifeSec even if the special died).
Export after a ladder of Special overrides (Sight → Hunger pull → Seek push → Drift) to see which knobs buy a seat in the remnant.
What “seconds” mean
History Dur / Long / lifeSec use sim time: ticks ÷ 60 (not wall-clock). At 10× speed, wall time is much shorter than Dur.
